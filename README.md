## 一、这是个什么问题：每开一个对话，AI 脑子先进来一大包

以我们实际在用的 **WorkBuddy** 平台为例。每开一个新对话，还没等你说话，平台就自动注入一批文件（云端画像、SOUL、USER、IDENTITY、跨项目 MEMORY、工作区摘要、身份卡……）：

<p align="center"><img src="assets/注入示意图.svg" width="680" alt="WorkBuddy 每轮注入示意：云端画像、SOUL、USER、IDENTITY、跨项目 MEMORY、工作区摘要、身份卡、自定义指令，合计约 45.6KB"></p>

**每轮都带，一份不少。问题从来不是"没有这些文件"，而是它们烂掉了**：

| 病灶 | 实证 |
|---|---|
| **重复** | "我是谁"写了 4 遍、"红线"写了 5 遍、"待办"记了 3 本账 |
| **只增不剪** | 办结项、版本史只往上摞，没有任何保鲜机制——写好就沉底 |
| **正本错位** | 该装魂的槽装着原厂英文模板；该指路的槽装着正本的副本 |

最狠的一条证据：画像里写着某位同事"在另一个平台"——**过期三个月，没有任何一个人发现**。每轮注入 ≈45.6KB，估计**一半在白吃**。

→ 详见 [操作说明书 · 问题篇](01-操作说明书/01-问题篇.md)

## 二、我们做了什么（说明书浓缩版）

1. **八槽分工、一份正本**：给每个注入槽位派一个唯一使命（魂答"我是谁"、USER 答"他谁"、身份卡答"我干什么"……），同一信息全层只许一份正本，其余一律指针；
2. **瘦身**：45.6KB → 10.9KB（−76%），没丢任何在干活的信息，丢掉的全是重复与过期；
3. **写魂**：不搬模板，用 AI 自己的话写自己；验收标准是"可执行"——有信号、有动作、可判违规；**有人味是约束的副产品，不是形容词的产物**；
4. **演化池**（最大亮点）：`谁发现 → 随手投池（只记不改）→ 定时消化 → 到期一次拍板`——正本一份，眼睛多双；
5. **全程纪律**：先备份、一步一报、不连动——改常驻层＝改 AI 的脑子。

→ 详见 [操作说明书 · 目录](01-操作说明书/00-目录.md)（**一件一章、一章一个模板**：开工准备→SOUL→USER→IDENTITY→MEMORY→身份卡→摘要→长期记忆→演化池→装完之后→案例→致谢，13 章）

## 三、达到了什么效果

- **数字**：注入 −76%；八条改进线零事故；每次变更三层留痕（稿次快照＋演进总账＋回滚点）；
- **体感**：AI 开场即定位，不再"每次重新交代"；过期信息随手被抓；人格资产第一次有版本、有演化史、可回滚。

## 五、三个最容易踩的坑（先剧透）

1. **"取精华"不等于"搬句子"**——抄结构可以，抄措辞就是把别人的魂穿在身上；
2. **有人味是约束的副产品**——想有人味，别加形容词，加禁令；
3. **同一信息只许一份正本**——第二份副本的保质期，通常撑不过三个月。
